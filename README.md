# Симулятор Палаты представителей · 2026

Тест про выборы в Палату представителей США 3 ноября 2026 года, 435 мест 120-го Конгресса. Интерфейс на русском и английском: переключатель RU / EN в шапке. Ответы собирают одномандатные округа, переводят долю голосов в места и проверяют, есть ли 218 голосов за спикера.

Палата не Кнессет. Здесь нет барьера 3,25% и метода д’Ондта. В округе один победитель. Голос за независимых почти всегда сгорает. Большинство в 218 ещё не значит спокойного спикера: крыло, которое больше запаса, может провалить кандидата, как это было с Кевином Маккарти в январе 2023 года.

Позиции крыльев - редакционная оценка по публичным голосованиям и заявлениям осени 2026 года. Имена лидеров это лица крыла, не прогноз их собственных округов. Цифры 238 и 197 на первом экране - округление опубликованных прогнозов начала октября 2026 года. Делёж этих мест по крыльям тоже редакционный.

Сенат и президентские выборы здесь не считаются.

## GitHub Pages

Сайт статический. В репозитории есть workflow [`.github/workflows/pages.yml`](.github/workflows/pages.yml): на каждый push в `main` он гоняет тесты, собирает `dist` и публикует Pages.

1. Создайте репозиторий на GitHub и запушьте туда ветку `main`.
2. Откройте **Settings → Pages → Build and deployment**.
3. В поле **Source** выберите **GitHub Actions**.
4. Дождитесь зелёного workflow **Deploy GitHub Pages**. Адрес будет вида `https://<пользователь>.github.io/<репозиторий>/`.

Свои ответы хранятся только в браузере.
